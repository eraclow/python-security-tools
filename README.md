# Python Security Tools

A collection of small, focused security and networking tools written in Python. This repository is intended for learning, experimentation, and practical security workflows.

> For educational and authorized testing purposes only.

---

## Tools Included

### 1. IP Scanner (`ip_scanner.py`)
A threaded IP scanner script with hostname resolution capabilities for fast network discovery.

### 2. Web Parser & Recon Tool (`web_parser.py`)
A lightweight web reconnaissance tool to parse links (`<a>`), forms (`<form>`), and input fields (`<input>`) from a target URL.

**Usage:**
```bash
python web_parser.py [http://example.com](http://example.com)
